# TARIG Hotel Booking

A React + Vite hotel booking platform for Gedaref, Sudan.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Demo accounts

- User: `user@tarig.com` / `user123`
- Admin: `admin@tarig.com` / `admin123`

## Features

- Responsive hotel discovery and search
- User signup, login, validation, and persistent sessions
- User profile editing and reservation dashboard
- Hotel booking and reservation cancellation
- Admin user CRUD
- Admin hotel CRUD
- Admin reservation management
- LocalStorage-backed application data
